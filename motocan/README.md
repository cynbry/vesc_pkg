# MotoCAN (Motocompacto VESC Bridge)

This package allows a VESC to interface with the Honda Motocompacto electric scooter. The display is communicated with
over CAN bus to show current speed in MPH and battery percentage. Mode 1/2 is communicated to the VESC to limit speed.

This is a **work-in-progress** and this early version is aimed at those who have converted their Motocompacto to VESC
and want to have their screen working. More to come!

## Current features

- Speed in MPH
- Battery %
- Mode 1 capped to 10MPH
- Mode 2 unlimited speed
- App controlled disable
