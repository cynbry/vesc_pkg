# MotoCAN (Motocompacto VESC Bridge)

Enables usage of the Motocompacto's display unit with a VESC controller or VESC Express module.

Currently supported features:

- Battery %
- Speed in MPH
- App controlled wheel lock

Not supported:

- Mode 1/2 (planned next)
- Rear hall status (needs GPIO)
- Light toggle (needs GPIO)
- Charging indicator (?)
