# MotoCAN (Motocompacto VESC Bridge)

This package is for individuals who have already converted their Motocompacto to VESC.

## Features

- Battery Percentage
- Speed in MPH
- Mode 1 capped at 10MPH, Mode 2 unlimited
- App controlled wheel lock (in original Motocompacto app)

## Planned Features

- Configure MPH/KPH
- Configure modes 1 & 2 speeds
- Reading hall sensor states
- Headlight control
- Braking light on brake
